# 回答质量与证据覆盖改造冻结（2026-10-29）

用户授权按上一轮建议处理：较宽科研综述以5–8篇直接相关文献为软目标、2–3篇可获取全文为优先目标，细分问题不凑数，综合写作而非摘要拼接。当前任务是第四阶段最小核心，附带修复直接妨碍回答的筛选/全文预算；不扩大到发送ack、中文FTS、完整评测平台或独立医学签署。

输入输出复用ResearchRequest/RetrievalResult/ResearchAnswer及现有飞书入口。保留top_k接口及默认5、上限20；要求8篇可显式top_k=8，但论文数不是成功门槛。检索仍最多2轮/4 HTTP、40候选/45秒；一篇直接论文即使覆盖所有维度，也在预算允许时继续找独立证据；不足时如实记录coverage不足，不能接纳不相关、过期或下游任务论文。相同规范题名+相同摘要的不同DOI载体只留一次，来源原始记录均保留。第二查询须有不同词法表达而不是无意义重放。

全文保持合法性/身份/来源定位/事务契约；最多3篇实际发生网络获取的论文、共享6个HTTP尝试与原35秒总预算。许可或URL预检失败不消耗论文获取名额；有效缓存不消耗下载名额。段落向量召回16项，补入最多4个匹配明确科研章节意图的缓存段，重排最多3段；支持中文通用方法/采集/结果/局限意图，不写医学疾病词表。正文不重新编码。研究总预算不增加，初始设计生成预留15秒，真实验收修订为25秒。

生成前按已经校验的摘要assessment.covered_dimensions组织跨论文chunk ID组，保留原文与全文层级；分组不是已证实结论。DTO增加可选section标签及evidence_groups（向后兼容），写作按技术方向/比较条件组织，可用短标题，无强制模板；不因检索截断就把每段改写为免责声明。关键指标必须引用原证据，不跨数据集排名。OpenAlex默认渲染只说明一次系统范围，保留研究特有限制；检索次数/截断数量/预算只在audit展示，摘要/实际引用全文及DOI链接仍可见。

## 集中验收中发现的必要修订

- OA段落数已改3，但EvidenceHit仍按2拒绝合法输入；现统一OA上限3，旧PMID上限2不变，增加真实数据流对应的三段校验断言。
- 8篇候选的query_rounds/candidate_outcomes撑大生成输入；从模型上下文移除，原provenance审计记录保持完整。上下文仍32k字符，不能保证所有全文均被保留。
- 原始方法论文可能只支持比较中的一侧。新增可选study_role（method_origin/comparison/other），先保留综合比较查询，再在第二轮分别补查两侧原始方法，仍最多四HTTP。约束匹配且有明确方法维度覆盖的partial method_origin可作单侧方法参考；保留partial判断，不允许constraints_match=false进入。生成上下文也传study_role，要求方法定义优先引用各自原研究，不把标签当结论。
- 补检新候选排在未筛旧候选之前，避免被同一个输入预算再次挤掉。相同题名/摘要的不同DOI不重复计研究。
- “technical challenges/bottlenecks”等通用分析措辞不是对象、任务或终点。只剔除明确分析措辞，核心研究约束和粗计划遗漏的终点仍保留。明确区分文档任务相关性与摘要已经覆盖哪些分析维度；后者不足可留空等待全文，不能因此拒绝所有任务匹配研究。
- 引用审计原先仅拿PMID判断是否被引用，导致OpenAlex全部误记selected_not_cited；现在按真实OpenAlex ID/文档ID/PMID分别关联，门禁强度不变。
- 未解决完整科研质量签署、各域名全文覆盖和飞书unknown ack，不纳入本轮伪通过。
- 真实比较题发现基线机制误归主模型，单纯增加提示未解决。比较意图补入Network architecture等架构章节，避免只拿对照实验段写模型设计；保留错误答案及修复后真实来源再生成对照，不将策略字符串测试算内容验证。
