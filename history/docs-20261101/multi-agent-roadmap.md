共享结构化状态拟包含：原始想法/约束、问题与 QueryPlan、search_provenance、文献/证据快照及 ID、方法分析、相似性、候选缺口、研究方向/方案、逐项事实/推断/假设标签、引用及支持状态、审核问题、返工记录、轮次与剩余时间/调用预算、最终报告状态。各节点引用同一可信快照，输出须校验后写入状态，不允许模型改写来源元数据或用户原始约束；具体 schema 在改造前冻结。

编排计划：Planner → Scout → Methods → Prior-Art & Gap → Design → Reviewer → 复用 Phase 7 报告输出。必要澄清可提前结束；Reviewer 可将来源不足定向退回 Scout、方法抽取问题退回 Methods、比较/缺口问题退回 Prior-Art & Gap、方案问题退回 Design。重新检索后须重做受影响分析并审核，不能沿用失效支持状态。
