# 从零理解证据分析

证据分析是把文献中能看到的方法、数据和结果整理成可回溯字段，并与用户科研想法比较。RAG 只负责找片段，检索得分不能代表研究重合程度。Phase 6 在现有检索之后增加一次受预算约束的模型分析调用。

底层分成两步：模型输出结构化候选；规则验证对象、精确引文和归属。reported_fact 的 value 必须等于某个引文，防止改写数字。model_inference 和 unverified_hypothesis 必须写明验证事项。引文真实也不证明推断正确，所以保留人工语义复核门槛。

六类方法字段是设计、数据、技术、指标、结果、局限；额外保留人群/干预/对照/结局/时间/样本量/效应/质量线索。没有信息就输出空值与 not_reported。相似性比较 question/population/data/methods/outcomes；任何未知维度使整体 unknown。缺口必须由文献依据引出，空检索不会调用模型，更不能据此宣称创新。

最小 Demo 见 demo.py。修改其引文但不修改原文，将触发 model_output_invalid。这里只证明结构及回指，没有执行 GRADE、全文审查或创新性鉴定。
