# 面试表达

30 秒口述：我们复用原 PICO、PubMed 和混合检索，在其后增加受限的结构化分析。事实保存精确引文，相似性逐维比较，缺口只作为待验证推断。确定性规则检查身份、定位、数字原文和双侧来源，模型语义仍由人工审核，空结果不能证明创新。

为什么不直接让模型写报告？Phase 6 先建立可验证分析契约，报告是 Phase 7 的单独任务。为什么不做六 Agent？当前单次调用足够，后续再按计划拆分。为什么 partial 不等于失败？partial 表示合法但字段、范围或相似性信息不足；格式和引用错误则拒绝，服务故障也不会伪装无研究。

能保证医学事实正确吗？不能。精确引文可在上下文中被误读，抽取和比较还需要真实样例与医学人工验收。不得把离线替身结果说成医学验证。
