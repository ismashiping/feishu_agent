# Phase 7 学习导航

本阶段把用户科研想法、检索、Phase 6 分析、来源核验、支持度审核和八部分报告连接起来。先读 [原理](tutorial.md)，再读 [执行路径](code-walkthrough.md)，运行 Demo 后完成 [练习](exercises.md)，最后用 [面试表达](interview.md) 和 [排错](troubleshooting.md) 复盘。

项目根运行 `.venv/Scripts/python.exe -X utf8 -I docs/learning/phase-07/demo.py`。合成文献和审查替身不访问网络；故意不存在的 PDF 快照和 uncertain 审查产生 verification_incomplete，展示系统如何保留未验证状态。不是医学研究报告样本或真实模型验收。

真实状态与实际命令见 [阶段记录](../../phase7-acceptance.md)。教材齐备不等于真实依赖和医学人工复核通过；本阶段没有实现 Multi-Agent。
