# 面试表达

30 秒口述：我们把原 PICO、PubMed、混合检索和方法分析接到同一 LangGraph 的报告分支。报告先验证来源身份、哈希和位置，再检查官方元数据，最后做一次模型支持度审核；所有结论保留事实/推断/假设标签。JSON、Markdown、CLI、API 和飞书共用同一结构，不会把空检索称为创新。

为什么引用有效还要审核？真实文献不一定支持这个结论。为什么 verified 不等于医学正确？模型判断和检索覆盖都有局限，仍需要真实样例及医学人工审查。如何处理核验失败？服务不可用保持 incomplete，身份冲突或不支持结论拒绝发布，不通过删除引用掩盖问题。

为什么没有多个 Agent？本阶段交付完整报告链路；后续多 Agent 改造单独规划，复用当前底层模块。如何避免成本失控？两次有界模型阶段、官方批量核验、共享总期限，不做无限审核反馈。
