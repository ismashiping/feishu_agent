# 从零理解离线评价

评价是把固定问题、证据、输出和预先标注的答案进行比较。固定数据可以发现改代码后的退步；没有固定标注，结果变化可能只是题目变了。

Recall@k = 前k个唯一片段中相关片段数 / 全部相关片段数。MRR 是首个相关片段名次的倒数再对问题平均。例：a 在第二位，Recall为1，倒数为1/2；另一个问题因超时无结果，二者平均分别为1/2和1/4。无相关片段的拒答题不加入召回分母，独立统计拒答。

身份准确率衡量引用是否匹配冻结来源ID；定位还要求片段位置匹配。真实来源依然可能不支持论断，所以 support 独立检查人工 supported_by 关系。覆盖率只问是否提供引用，引用存在不代表引用正确。没有引用则覆盖率缺失，不能通过删除引用得到高分。

微平均累计引用或claim的分子/分母，宏平均对问题平均。0/0不可解释，输出null；unknown/disagreement人工标签也不得当真。门槛在实验前冻结，不能看到结果后降低阈值。所有失败保留；模型错误与依赖错误分开。

性能实验包含资源生命周期：启动tracemalloc → 建线程池 → 全部任务结束 → 记录峰值 → finally停止跟踪。这里测Python评价函数，CPU线程不证明服务吞吐。模型加载、连接池、拒绝、真正满载要另做受控服务实验。
