# 面试表达

问：如何避免科研RAG变成摘要复述？

30秒回答：我先按研究对象、任务和时间筛选文档，去掉相同工作的重复载体，再把已校验摘要的覆盖维度组织成跨论文chunk组。高价值论文走合法全文缓存和章节召回，在同一次模型调用中按技术方向比较，而不是每篇输出一段。每条结论仍绑定真实原文，跨数据集指标不直接排名。

问：为什么不强制至少五篇？

30秒回答：数量只是补检触发信号。宽主题通常希望五到八篇，但细分方向可能只有少量直接证据。系统最多补检两轮，保留任务和日期限制；不足就说明覆盖缺口，不能用无关或旧论文填满。技术成功和科研质量验收分别记录。

问：如何控制全文成本？

30秒回答：先查稳定键缓存；只有发生HTTP才计获取尝试，元数据许可拒绝不占名额。最多三篇、六HTTP、固定总时间，正文不变不重复Embedding。文档内向量候选加少量章节候选，重排最多三段，上下文有硬上限，给生成预留25秒。

问：引用通过意味着什么？

30秒回答：它证明模型引用的ID属于本次证据，元数据和原文位置能追溯，不证明数值解释或医学支持关系正确。真实案例、关键数值和跨研究推断仍需要独立语义复核，失败不能靠删除坏引文改成成功。
