# 面试与30秒表达

问：为什么不把同步业务改成async？答：结构迁移的目标是保持现有行为；原依赖通过有界线程池适配，改变执行机制会扩大风险。

问：为何关闭先等线程池？答：运行任务仍借用数据库和HTTP资源，先关闭这些资源会让正在执行的任务访问失效对象。

问：如何验证API兼容？答：完整OpenAPI快照、全部既有边界测试、在线scope错误映射和饱和恢复、lifespan隔离及资源关闭测试共同验证；再比较完整回归失败身份。

30秒口述：我将FastAPI工厂、路由、Schema、ASGI边界和有界执行拆成API包，保留create_app和api_runtime兼容导出。原同步业务、请求ID、错误码、容量及资源生命周期不变。用冻结OpenAPI、隔离导入、生命周期与在线错误/并发测试验证，并保留历史失败，不把离线验证当成真实医学验收。
