# 面试表达

问：为什么不是换API就完成？
答：来源ID、摘要结构、日期、缓存和引用快照都是契约。OpenAlex记录不能塞进PMID，否则来源追溯失真。

问：为什么语义筛选后还要严格校验？
答：模型可能返回错误ID、改写quote或额外字段。ID集合校验后逐篇校验，错误项排除并标partial；通过关联校验仍不代表科学判断正确。

问：如何控制成本？
答：最多两轮、四个HTTP尝试、两次筛选，输入输出字节和总期限受限；正文向量化归后续全文阶段。未计量Token就不报具体费用。

30秒口述：我复用项目的Planner、LangGraph、模型和飞书链路，加入结构化科研约束与动态日期，把在线发现切为OpenAlex。先规范化和去重，再用带原文依据的语义判断筛选文献，只有质量缺口才补检。引用来自保存的快照，摘要和全文严格区分。用真实响应fixtures、离线链路测试和真实模型检查分别验收，保留失败与人工医学复核缺口。
