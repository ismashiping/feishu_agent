# 角色化编排是什么

Agent角色在此是具有清晰输入输出、工具边界与职责的工作流节点，不等于必须创建不同模型或并发进程。IdeaPlannerAgent只负责调用已有PicoPlanner；LiteratureScoutAgent只负责现有来源检索。LangGraph保留统一路由，领域模块继续负责引用和原文真实性。

共享WorkflowState包含用户请求、全局deadline、规划、检索、分析、报告及内部agent_steps。每个角色返回局部patch，由图合并；角色实例不保存当前请求或上次输出，避免跨请求污染。原文和来源仍经既有Pydantic校验，角色不能因为想继续执行而放宽门禁。

当前图没有回边，规划最多一次、检索沿原scope执行，不额外消耗模型预算。方法分析/候选缺口/报告审核仍在原模块，设计角色和有限反馈留后续独立任务。已有失败观察基线不代表医学质量，本轮目标是职责可替换且行为兼容。
