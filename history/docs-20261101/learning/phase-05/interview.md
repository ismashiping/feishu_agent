# 面试表达

为什么用RRF？关键词与向量分数不可比较，RRF用各路排名进行简单确定的融合，保留可解释的通道贡献。

怎么保证一致性？同一只读可重复读事务内查询两路候选与来源，并按chunk身份、原文区间和hash重建，避免把不同快照拼成同一个证据。

同文献两片段如何处理？本地融合只按chunk_id去重，不能按document_id把不同证据消掉；同chunk来源不一致拒绝，而非随机选一个。

中文支持怎么说？向量沿用多语言模型；关键词目前只验证ASCII simple词项，不把数据库默认解析器说成中文分词器。中文问题可显式给英文检索词，并保留原问题。

30秒口述：我复用PostgreSQL和已有医学证据链，加一个自动生成FTS列与GIN索引，用同一数据库快照取关键词/向量候选，按chunk_id做固定RRF。结果保留通道排名与原文定位，失败不静默降级，引用仍走原门禁。用手算和真实数据库验证，模型效果、性能调优和研究质量分别验收。
