# 面试与口述

为什么不让模型直接生成检索语句？先保留原问题和可信来源区间，将扩展词与用户条件分开，后续检索器可以消费明确契约；现阶段不提前实现在线语法。

Pydantic 能证明临床正确性吗？只能验证结构和应用内约束；原文 span 可证明字段来自输入，不能证明分类或医学结论正确。真实模型小样例与人工复核不能用 Fake 替代。

为何保留整个原问题？避免模型漏抽否定、剂量、人群与时间约束而不可追溯。它是保守的完整性措施，不是已完成过滤器或医学推理。

为何复用 LangGraph 和 LangChain？现有共享服务已定义编排与模型边界，只增加 plan/clarify，避免重复服务或框架。

30 秒口述：我在现有医学 RAG 中增加一次受限 PICO 抽取，严格区分用户原文与同义词扩展，以码点区间校验出处。缺比较项保持为空，只有明确意图歧义才走澄清分支，其他问题复用既有检索与引用门禁。测试先按契约编写，阶段末集中验证；模型语言理解与结构正确性分开验收。
