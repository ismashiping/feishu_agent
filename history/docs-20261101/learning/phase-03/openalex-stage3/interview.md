# 面试问答

问：OpenAlex链接能直接下载吗？
答：先检查具体location的OA与许可，再检查主机和重定向；文件还要按DOI、题名核验身份。能打开PDF不代表它是目标论文，也不代表允许再利用。

问：为什么两种hash？
答：原响应hash用于追溯下载，解析表示hash用于判断正文是否改变。OAI响应日期变化不应导致相同正文重新Embedding。

问：缓存更新中间失败怎么办？
答：索引和向量在同一事务完整替换，写锁避免同一论文交错发布；失败保留旧索引。签名防止不兼容模型或解析版本混用。

问：引用检查能保证医学正确吗？
答：它能验证来源、段落ID和位置关联，不能替代医学语义蕴含或专家签署。摘要、全文段落和综合推断必须分别表达。

30秒口述：我在现有OpenAlex候选筛选之后接入合法全文，复用PDF/XML、LlamaIndex、E5和pgvector。按DOI核验和缓存论文，保存解析表示及章节页码。问题先选文档再取段落，缓存命中不重新下载和编码，更新用事务保证完整性。许可或身份失败则如实回到摘要，测试区分协议、真实网络、模型、数据库和医学复核。
