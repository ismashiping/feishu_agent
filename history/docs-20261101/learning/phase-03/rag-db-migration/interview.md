# 面试与30秒表达

问：为什么没有把application.retrieval搬到rag？答：它协调检索端口、选项和领域规则，已有独立用例职责；本轮优先移动基础设施实现，不为目录改写业务边界。

问：为什么兼容文件使用模块别名？答：旧调用者依赖模块级注入和私有辅助符号，需要与新模块共享全局；模块对象同一还能防止ORM和锁重复创建。

问：如何保障数据库没有被目录变化影响？答：保留全部持久化模块和事务代码，冻结所有表与索引DDL、九份迁移文件hash，并复用原数据库边界Fake测试；真实数据库未运行时单独保留未验证事实。

30秒口述：我把21个已有适配模块归入rag、integrations和db，保留application用例和领域规则。以旧新模块同一对象兼容既有注入，所有活动调用方改用新导入。用AST、DDL与迁移hash冻结，以及解析、引用、检索和资源回归验证，未借结构整理改算法或数据库Schema。
