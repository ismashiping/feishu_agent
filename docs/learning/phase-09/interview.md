# 面试表达

问：为什么不用LLM评分决定医学正确？答：来源身份和位置可以确定性检查，结论支持仍需合格人工标注。模型评分只能辅助，不能把自评当金标准。

问：超时是否排除？答：保留在端到端成功率和相关问题召回分母中，引用精度没有实际引用就不适用；同时看覆盖率，避免只看成功样本产生选择偏差。

问：基线怎样防误比？答：固定dataset、标注、门槛和模型/检索配置hash；不兼容输出inconclusive，不自动覆盖旧基线。源码hash另记录，允许比较代码改进效果。

30秒口述：我做了可追溯离线replay评价，分开计算检索、引用身份、定位和人工支持关系，保留失败与空分母，提供固定门槛和回归delta。报告保存输入和源码锁hash。合成数据验证公式，历史真实失败另存，缺医学审查不会自动通过；性能仅测固定评价器，未承诺服务容量。
