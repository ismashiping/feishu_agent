1. 运行 demo.py，尝试 online、hybrid、local 和未知值，记录哪些在输入边界失败。验证失败时不创建 runtime。
2. 阅读 test_retired_local.py，为三个科研 HTTP 路由补齐参数拒绝断言，检查状态码和无服务调用。
3. 在隔离测试中给 oa_store 注入已有缓存，使下载替身一旦被调用就失败；验证缓存命中不下载。再让 load 返回 None，验证未命中走获取路径。复用 test_oa_fulltext.py 的 fixture，禁止下载虚构地址。

5. 独立画出一次 API 请求持有哪些资源、何时关闭，再与 runtime 和 lifespan 核对。
