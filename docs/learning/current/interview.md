# 面试与 30 秒口述

**系统怎么运行？** 用户问题先经规划，在 OpenAlex 发现并筛选论文，再对选中论文复用本地全文缓存或下载全文。系统切分、编码并选择段落，生成回答或结构化分析，再检查引用定位与来源身份。缓存降低重复获取成本，但当前不是全库本地与在线联合检索。

**为什么不用很多 Agent？** 角色划分帮助组织职责，LangGraph 负责流程；Methods 等角色复用现有联合抽取，不为每个角色重复调用模型。工程价值来自可解释调用链和边界保障。

**类型检查能保证什么？** 它发现不匹配的调用、可空值误用和变量推断冲突，不验证网络 JSON，也不证明医学结论。Pydantic 负责边界契约，pytest 验证行为，人工审查医学语义。

**验收通过是什么意思？** 必须说明代码版本、命令、依赖、排除项和真实结果。离线全绿不代表飞书交付或医学正确。正式验收按范围给结论，未验证保留未验证。
