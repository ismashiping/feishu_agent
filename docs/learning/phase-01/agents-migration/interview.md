# 面试与30秒口述

问：为什么ResearchService没有搬进graph.py？答：服务协调检索、生成、分析、报告和最终输出；graph.py只声明执行结构，分开后业务契约和框架装配各有位置。

问：为什么保留旧模块？答：已有测试和学习Demo引用旧路径。兼容模块重导出同一对象，不保留两套算法，等调用者迁移且获确认后再考虑删除。

问：如何证明结构迁移没有改变业务？答：冻结完整双拓扑、状态类型、公开签名和OpenAPI，复用结果、反馈、并发与资源测试；比较完整回归失败身份。静态拓扑相同不能替代业务测试，离线通过也不能代表真实医学验收。

30秒口述：我将请求状态和六个角色迁到agents包，提取一个只注册原绑定节点和边的图构建函数。ResearchService保留原业务方法、时间预算和返回契约。旧导入重导出同一对象，通过冻结拓扑及状态、接口和既有行为回归检查兼容性，并保留历史失败和真实依赖未验收事实。
