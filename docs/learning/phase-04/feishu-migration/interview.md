# 面试题与口述答案

## 为什么飞书回调不直接执行科研任务？

回调需要快速返回，而科研和模型调用耗时且可能失败。项目用有界 Dispatcher 接纳任务，把容量状态明确返回给 Receiver，避免 SDK 线程被长任务占用，也避免无界排队耗尽资源。

## Redis 去重为什么使用带 owner 的 Lua 租约？

Lua 保证检查与修改原子执行，owner 防止旧 worker 删除新 worker 的租约。processing 有期限，成功发送后才转 completed；未知网络结果不能盲目重试，否则可能重复发送。

## 为什么旧模块要和新模块共享同一对象？

历史调用方和测试会 monkeypatch 模块全局。如果只复制导出的类和函数，函数仍读取 canonical 模块的全局，旧路径上的 patch 不生效。共享 `sys.modules` 对象可以保留这一运行时契约，同时只有一套实现。

## 结构迁移如何证明没有改业务算法？

迁移前冻结当前工作区源码，测试把明确的内部导入路径和日志名归一化后比较 AST；再运行旧测试、新旧模块身份测试、入口测试和全量离线回归。真实服务未执行的部分单独列为未验证。
