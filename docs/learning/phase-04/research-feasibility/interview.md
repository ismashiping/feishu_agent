# 面试表达

问：为什么不用多个独立Agent做分类？

30秒：系统复用一次结构化规划，在同一LangGraph中路由。减少额外模型调用，也让所有分支共享期限、请求身份和证据契约。角色分工是调用职责，不必等于独立模型进程。

问：如何避免无证据的可行性结论？

30秒：四维判断要么带真实片段引用，要么明确unknown。推断和候选实验必须有验证步骤，实验必须关联现有候选缺口。引用还会进入报告审核，但来源合法不等于科学结论正确，仍保留人工复核。

问：如何评价效果？

30秒：隔离测试验证路由、预算和引用门禁；真实四题验证模型与服务链路，飞书日志加用户实收验证投递。科研相关性、方法归属和机会价值需要独立标签，不能用测试通过率替代医学质量。
