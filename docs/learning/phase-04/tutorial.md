# 从检索到真实来源

PubMed 提供文献元数据与摘要。ESearch 把查询变为 PMID 列表；EFetch 根据这些 PMID 返回 XML。先确定身份，再获取来源，才能避免让模型凭记忆生成文献。在线获取不等于读取全文，也不等于医学结论已获支持。

应用先发送明确 query（未指定时使用原问题/QueryPlan），记录实际查询及官方 query_translation。它没有自动构建 MeSH，也不保证自然语言查询已完整实施否定、人群或剂量过滤。

XML 字段映射复用原离线实现：内嵌标签保留文字，团体作者不猜拆，日期保持精度。无摘要的条目保留 metadata_only，不伪造证据。每条响应安全解析后序列化为规范化 XML 快照并取 SHA256；哈希证明本次数据的一致性，不证明文献结论正确。

先理解限制再跑 Demo：最多20条、每批10、总期限30秒、最多8个HTTP尝试。每进程全局门限制请求串行且至少间隔0.34秒，即使有key也不提高速率。不同进程/主机不共用门，生产只能单个启用在线检索的实例；同IP其他工具也占官方配额。

hybrid 是本地与在线来源合并，各预留名额、PMID去重，本地在前。在线分数只是1/rank，未计算向量；两种分数不相加。关键词和向量融合属于Phase5。
