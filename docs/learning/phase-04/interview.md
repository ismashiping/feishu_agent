# 面试与30秒表达

为何先ESearch再EFetch？第一步确定真实PMID及检索范围，第二步获取官方元数据和摘要；模型只消费证据，不生成文献身份。

来源存在是否意味着支持结论？不是。该阶段验证身份、文本来源和定位；语义支持与正式研究质量仍需要后续核验及人工复核。

如何处理缺摘要和服务故障？前者是合法metadata_only记录；后者是失败或partial，不能统称证据不足。没有可用记录的partial不发布正常回答。

为什么不立刻把在线来源入库？在线任务快照足够支持本次追溯，永久版本与增量更新属于Phase8；避免把检索变成隐式写操作。

30秒表达：我在原医学RAG上接入PubMed官方搜索和批获取，复用已有XML映射和引用门禁。每次保留实际查询、时间、PMID、规范化快照哈希和摘要范围；缺摘要不造证据，部分失败不当作完整零结果。全进程请求门、总期限及有限重试控制外部边界，混合来源先保留名额去重，后续再做真正混合检索排序。
