# 修改练习与独立实现

先阅读tests/unit/test_api_runtime.py的取消等待、submit失败释放和关闭等待测试；再运行test_api_migration.py的在线错误映射、双应用隔离和饱和恢复测试。

修改练习（独立练习分支）：将busy错误误改为500，运行饱和测试，解释客户端何时可重试。再把请求等待取消等同于释放名额，说明为何已有取消测试会发现资源超额。完成后恢复练习改动，不修改冻结断言。

独立实现：在仓库之外的临时脚本写一个单工作者有界执行器，用两个Event控制工作，验证第二个任务被拒绝、健康函数仍可执行、释放后可再次提交、关闭后拒绝新任务。不得用sleep替代明确同步信号，不接真实医学业务。

验收：能解释transport边界与领域校验的区别、线程池Future与HTTP等待者的关系、退出资源顺序及Fake测试不覆盖的真实依赖。
